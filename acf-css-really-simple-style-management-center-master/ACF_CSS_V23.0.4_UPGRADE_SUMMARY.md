## 🔧 사용 방법

### 빠른 검색
1. **Ctrl+K** (Windows) 또는 **Cmd+K** (Mac) 누르기
2. 검색어 입력 (예: "색상", "폰트", "버튼")
3. 결과 클릭하여 해당 섹션으로 이동

### 키보드 단축키
1. **?** 키 누르기
2. 단축키 목록 확인
3. 각 단축키 사용

### 컨텍스트 메뉴
1. 섹션에서 **우클릭**
2. 원하는 액션 선택
   - 설정 복사
   - 기본값으로 재설정
   - 섹션만 내보내기

### 툴팁 보기
1. 필드 레이블 옆 **?** 아이콘에 마우스 올리기
2. 또는 필드에 마우스 올리기 (data-tooltip 속성이 있는 경우)
3. 도움말 확인

### 넛지 메시지
- 자동으로 표시됩니다
- 상황에 맞는 안내가 표시됩니다
- 닫기 버튼으로 닫을 수 있습니다
